# Third-party software

This repository contains the benchmark's readout and analysis code. Upstream
feature-extraction runtimes, model parameters and datasets are obtained
separately.

Relevant upstream projects must be acquired separately under their own terms:

- AlphaFold 3: https://github.com/google-deepmind/alphafold3
- AlphaFold: https://github.com/google-deepmind/alphafold
- ESMC implementation used in the study: https://github.com/Biohub/esm
- dMaSIF: https://github.com/FreyrS/dMaSIF
- Rosetta/PyRosetta: https://www.rosettacommons.org/
- PyTorch: https://pytorch.org/
- e3nn: https://e3nn.org/
- scikit-learn: https://scikit-learn.org/

Each upstream project retains its own license and model/data terms. This
repository currently has no project-level LICENSE file; no upstream license
is implicitly applied to the benchmark code.
